# Audio Sources — Curated CC0/Public-Domain Candidates

The repository baseline does not embed third-party binary audio yet. The Unity runtime contains procedural fallback SFX so the MVP is audible immediately. For production-quality replacements, the following sources were selected because their pages state CC0/Public Domain licensing.

## Impact / melee / construction
- OpenGameArt — Impact (CC0): https://opengameart.org/content/impact
- OpenGameArt — 75 CC0 breaking / falling / hit SFX: https://opengameart.org/content/75-cc0-breaking-falling-hit-sfx
- OpenGameArt — Metal Impact Sounds (CC0): https://opengameart.org/content/metal-impact-sounds

## Archery / weapon handling
- OpenGameArt — Medieval sound effects - Weapon Textures (CC0): https://opengameart.org/content/medieval-sound-effects-weapon-textures
- OpenGameArt — Fantasy Weapons and Apparel SFX Library (CC0): https://opengameart.org/content/fantasy-weapons-and-apparel-sfx-library
- OpenGameArt — Fantasy Sound Effects / Tinysized SFX (CC0): https://opengameart.org/content/fantasy-sound-effects-tinysized-sfx

## Import convention
After downloading, place production clips under:
`Assets/GeometricStrategyGame/Audio/`

Recommended names:
- sfx_hit_01
- sfx_arrow_01
- sfx_wolf_01
- sfx_bear_01
- sfx_eagle_01
- sfx_victory_01
- sfx_defeat_01
- sfx_upgrade_01
- sfx_build_01
- sfx_harvest_01
- sfx_coin_01

Always re-check the source page's current license before redistribution, and preserve a local copy of license/source metadata alongside imported production assets.
